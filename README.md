# 🥷 つるふぇったの手裏剣修行  
**Tsurufetta's Shuriken Training**

忍者になって手裏剣を投げるアクションゲームです。  
的の中央を狙ってアイテムを集め、氷爆弾を撃ち落とそう！

## プレイ方法

1. スタート画面で段位を選ぶ（最初は**初段のみ**）
2. 左右ボタンで照準を合わせて「手裏剣！」
3. 的の**中央**に当てるとアイテムGET
4. 氷爆弾は手裏剣で撃ち落とす（落とせないと毒＋ダメージ）
5. 段位クリアで次の段が解放。上段クリアで特別演出

## 段位と解放

| 段位 | クリア条件 | 備考 |
|------|------------|------|
| 初段 | 中央ヒット 5回 | 最初から遊べる |
| 中段 | 中央ヒット 8回 | 初段クリアで解放 |
| 上段 | 中央ヒット 12回 | 中段クリアで解放 |

## アイテム

| 色 | アイテム | 効果 |
|----|----------|------|
| 青 | 👑 水の王冠 | 次の投擲が二刀流 |
| 緑 | 🍵 お茶 | 「ありがと！」 |
| 赤 | 🧊 氷爆弾 | 敵攻撃を消し飛ばす |
| 黄 | 🌸 花 | 手裏剣増加＋ボイス |

## GAME OVER

氷爆弾の被弾回数が上限に達するとGAME OVER  
（初段10回 / 中段8回 / 上段6回）  
ロボつるん出現 ＋「まだまだ修行が足りないね。特訓するよ。」→ スタートへ

## 上段クリア特別演出

- 湯上がりつるんロボ登場
- 「も、もしかしてあなたはて、伝説の忍者？」ボイス
- **Xでシェア**ボタンで結果を投稿可能 → その後ゲーム再開
